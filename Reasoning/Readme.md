# ⚡ Reasoning Practice System

For **every topic**:

### Phase 1 — Learn

* [ ] Understand the concept
* [ ] Learn the common patterns
* [ ] Study solved examples
* [ ] Create short notes
* [ ] Solve 5 basic questions

### Phase 2 — Practice

* [ ] 10 Easy questions
* [ ] 10 Medium questions
* [ ] 5 Difficult questions
* [ ] Record mistakes
* [ ] Identify recurring patterns

### Phase 3 — Speed

* [ ] Solve 10 questions under a time limit
* [ ] Track accuracy
* [ ] Track average time/question
* [ ] Identify slow question types
* [ ] Practice weak patterns

### Phase 4 — Revision

* [ ] Revision after 1 day
* [ ] Revision after 7 days
* [ ] Revision after 21 days
* [ ] Reattempt incorrect questions
* [ ] Take mixed-topic test

## 🧠 Golden Rule

> **Logical reasoning is not about guessing the answer. It is about identifying the structure, eliminating impossible options, and reaching the conclusion with minimum wasted time.**
