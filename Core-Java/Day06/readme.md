## switch, break, default && ternary concepts

Program 1: Take a number from the user using Scanner.
Rules:
1 → Monday
2 → Tuesday
3 → Wednesday
4 → Thursday
5 → Friday
6 → Saturday
7 → Sunday
Any other number → Invalid Day
Use:
switch
case
break
default
Scanner
test cases:
1
7
0
8

Program 2: Simple Calculator using switch
Take three inputs:
First number
Operator: +, -, *, /
Second number
testcases
10 + 5
10 - 5
10 * 5
10 / 5
10 % 5

Program 3: Take a number using Scanner and print whether it is Even or Odd using the ternary operator only.
Rules:
Use Scanner
Use %
Use ?:
Don’t use if-else
Test with 8, 7, 0, and -5

Program 4: Largest of Two Numbers.
Take two numbers using Scanner.
Using only the ternary operator, print:
"a is greater" if a > b
"b is greater" if b > a
"Both numbers are equal" if both are equal
testcases:
10, 5  → First number is greater
5, 10  → Second number is greater
7, 7   → Both numbers are equal
