# 17. Java Database Connectivity — JDBC

> JDBC is kept as **one complete section** because it forms a single database-connectivity module.

JDBC allows Java applications to connect to relational databases and perform SQL operations.

## JDBC Architecture

JDBC consists mainly of:

### JDBC API

Provides Java interfaces/classes for database interaction.

Important interfaces:

- `Connection`
- `Statement`
- `PreparedStatement`
- `CallableStatement`
- `ResultSet`

### JDBC Driver

Acts as the bridge between Java applications and the database.

## Establishing JDBC Connection

Standard JDBC workflow:

```text
Java Application
       ↓
JDBC API
       ↓
JDBC Driver
       ↓
Database
       ↓
ResultSet
       ↓
Java Application
