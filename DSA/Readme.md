# 📈 Problem-Solving Workflow

For every DSA problem:

1. [ ] Understand the problem
2. [ ] Identify the pattern
3. [ ] Write brute-force approach
4. [ ] Analyze time complexity
5. [ ] Analyze space complexity
6. [ ] Optimize the approach
7. [ ] Implement in Java
8. [ ] Test edge cases
9. [ ] Write final complexity
10. [ ] Add solution to GitHub
11. [ ] Revise after 1 day
12. [ ] Revise after 7 days
13. [ ] Re-solve without looking at the solution
