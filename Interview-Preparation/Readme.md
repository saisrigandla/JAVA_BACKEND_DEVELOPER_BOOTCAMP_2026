# 5. 🔌 JDBC

JDBC allows Java applications to communicate with relational databases.

## JDBC Architecture

**Java Application → JDBC API → JDBC Driver → Database**

### JDBC API

- `Connection`
- `Statement`
- `PreparedStatement`
- `CallableStatement`
- `ResultSet`
- `ResultSetMetaData`
- `DatabaseMetaData`
- `Driver`

### JDBC Drivers

- [ ] Type 1 — JDBC-ODBC Bridge
- [ ] Type 2 — Native API
- [ ] Type 3 — Network Protocol
- [ ] Type 4 — Thin Driver

> **Type 4 is the commonly used JDBC driver.**

### JDBC Connection Steps

1. [ ] Import `java.sql`
2. [ ] Load/Register Driver
3. [ ] Establish Connection
4. [ ] Create Statement / PreparedStatement
5. [ ] Execute SQL Query
6. [ ] Process ResultSet
7. [ ] Close Resources

### CRUD

- [ ] Create / INSERT
- [ ] Read / SELECT
- [ ] Update / UPDATE
- [ ] Delete / DELETE
